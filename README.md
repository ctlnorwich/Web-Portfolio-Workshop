# Web Portfolio Workshop

Variations of the web portfolio workshop. Please check the different branches to find an appropriate starting point.

This is a simple web portfolio site. The latest version features:

- Folder-based pages
- A minimal stylesheet with custom properties and css nesting
- A basic dark mode toggle script with local storage
- If you are  using this with GitHub pages, you may need to update the home url from `\` to `\name-of-your-project`.
